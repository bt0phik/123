# FarSight LOD — сборка через GitHub

Этот проект настроен для автоматической сборки на GitHub Actions, чтобы не устанавливать Java/Gradle на компьютере.

## Что сделать
1. Открой https://github.com/new и создай репозиторий с любым названием, например `FarSightLOD`. Можно выбрать **Private**. Не добавляй README или другие файлы при создании.
2. На странице пустого репозитория нажми **Add file → Upload files**.
3. Распакуй этот ZIP на компьютере. Открой папку `farsight` внутри архива и перетащи ВСЁ ЕЁ СОДЕРЖИМОЕ (включая скрытую папку `.github`, если она видна) на страницу загрузки GitHub. Важно: `.github/workflows/build.yml` должна оказаться в корне репозитория, а не внутри ещё одной папки `farsight`.
4. Нажми **Commit changes**.
5. Открой вкладку **Actions** в репозитории. Дождись запуска `Build FarSight LOD`. Если сборка зелёная, открой запуск и внизу раздел **Artifacts**, скачай `FarSightLOD-JAR.zip`. Внутри будет `.jar`.

Если сборка красная, открой её, нажми шаг **Build mod**, скопируй ошибки и пришли их сюда — будем исправлять уже по конкретному логу.

Примечание: успешная компиляция ещё не гарантирует, что мод работает без проблем в игре. Нужна проверка в Minecraft 26.3 с Fabric.
